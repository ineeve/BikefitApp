# Bike Fit Analyzer (Android)

Android app that uses side-view video and pose estimation
to analyze bicycle fit and recommend adjustments.

## Features (MVP)
- Video capture via CameraX
- On-device pose estimation (MediaPipe Pose)
- Manual bike calibration
- Knee / hip / torso angle analysis
- Saddle height and reach recommendations
- Visual overlays

## Constraints
- Side view only
- Stationary bike
- Single rider
